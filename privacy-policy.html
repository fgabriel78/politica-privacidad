Summary: Privacy by Design

Your privacy is our core engineering principle. DIGI Router was deliberately built as a local-first utility. We do not track you, we do not operate telemetry servers, and your router credentials never leave your home network.

🔒 Local-Only Operation

Communicates directly between your Android device and your router over your local Wi-Fi. No intermediary cloud servers exist.

🚫 Zero Tracking & Ads

No Google Analytics, no Firebase Crashlytics, no advertising frameworks, and no behavioral tracking libraries whatsoever.

🔑 Hardware-Encrypted Storage

If you choose to remember your password, it is stored encrypted with AES-256-GCM via the Android Keystore.

📦 No Cloud Backups

Android auto-cloud backup is explicitly disabled in the app manifest, preventing any credentials from syncing to cloud drives.

1. Data We Process and How It Is Handled

The application processes only the technical data strictly necessary to communicate with your router and perform on-device network diagnostics:

A. Router Credentials

  • Data processed: Router IP address (e.g., 192.168.1.1), username, and administrative password.
  • Purpose: Authenticating directly with the router's local web administration service to read status and apply user commands.
  • Storage & Security: If you check "Remember password", the password is saved solely inside private application storage via Android's EncryptedSharedPreferences backed by the hardware-protected Android Keystore (AES-256-GCM and AES-256-SIV). It is never transmitted over the Internet or shared with any third party.
  • Retention: Stored locally until you sign out, disable "Remember password", clear app data, or uninstall the app.

B. Local Network Topology & Connected Devices

  • Data processed: Connected device hostnames, MAC addresses, local IP addresses, signal strength, link speed, and connection interfaces (Ethernet / Wi-Fi band).
  • Purpose: Displaying your home network map, EasyMesh node hierarchy, Wi-Fi 7 / MLO details, and signal diagnostics.
  • Local Discovery: The app performs local multicast discovery (mDNS on UDP port 5353, SSDP on UDP port 1900, and HTTP device description queries) strictly on your local subnet to resolve friendly vendor/model names.
  • Storage: User-customized labels (e.g., "Living Room TV") are saved locally in private SharedPreferences on your phone. None of this data is uploaded anywhere.

C. Fiber Optics & Hardware Telemetry

  • Data processed: GPON/XGS-PON optical attenuation (Rx/Tx dBm power), transceiver voltage, laser bias current, and temperature read directly from router hardware OIDs.
  • Purpose: Providing physical fiber health checks and helping you detect dirty optical connectors or link degradation.
  • Storage: Processed in real time in memory; not recorded or uploaded.

D. Wi-Fi QR Code Generation

  • Data processed: Your Wi-Fi SSID and pre-shared key.
  • Purpose: Generating a standard Wi-Fi QR code so family and guests can easily join your network.
  • Storage & Security: Rendered entirely on-device using local vector drawing and the open-source ZXing library. No remote generation APIs or servers are involved.

2. External Network Communications

The app operates exclusively within your local area network (LAN), with the following explicit exceptions initiated only upon user request:

Feature Target Service Data Exchanged Purpose
Speed Test Cloudflare CDN (speed.cloudflare.com) Standard HTTP ping, download, and upload data streams; public IP address visible in TCP handshake. Measuring internet download throughput, upload throughput, latency, and jitter. Governed by Cloudflare's Privacy Policy.
Dual Diagnostic Public DNS Resolver (1.1.1.1) ICMP ping / TCP latency packets Benchmarking total mobile-to-internet latency against router-to-internet latency to isolate Wi-Fi bottlenecks from fiber carrier issues.

No other external connections are ever established. The app does not ping developer servers, check license servers, or send crash telemetry.

3. Android Permissions and Why They Are Required

Permission Android Manifest Identifier Specific Technical Need
Network Access android.permission.INTERNET Enables direct TCP/HTTP communication with the router's local IP address and running bandwidth/latency benchmarks.
Network State android.permission.ACCESS_NETWORK_STATE Allows verifying active Wi-Fi connectivity before attempting connection to the local router IP.
Multicast Wi-Fi android.permission.CHANGE_WIFI_MULTICAST_STATE Required by the Android system to send and receive multicast UDP packets (mDNS and SSDP) for discovering local network device models (printers, smart TVs, IoT).

1. Datos que Tratamos y Cómo se Gestionan

La aplicación trata únicamente los datos técnicos indispensables para comunicarse con tu router y ejecutar diagnósticos de red en el propio dispositivo:

A. Credenciales del Router

  • Datos tratados: Dirección IP del router (ej. 192.168.1.1), nombre de usuario y contraseña de administración.
  • Finalidad: Autenticarse de forma directa en el panel web local del router para consultar el estado y ejecutar las órdenes solicitadas por el usuario.
  • Almacenamiento y Seguridad: Si marcas «Recordar contraseña», la clave se guarda exclusivamente en el almacenamiento privado de la app mediante EncryptedSharedPreferences con respaldo en el hardware seguro Android Keystore (cifrado AES-256-GCM y AES-256-SIV). Nunca se transmite por Internet ni se comparte con terceros.
  • Conservación: Permanece en tu dispositivo hasta que cierres sesión, desmarques la casilla de recordar, borres los datos de la app o la desinstales.

B. Topología de Red y Dispositivos Conectados

  • Datos tratados: Nombres de host, direcciones MAC, IPs locales, intensidad de señal Wi-Fi, velocidad de enlace e interfaz de conexión (cable / banda Wi-Fi).
  • Finalidad: Mostrar el mapa de tu red doméstica, la jerarquía de nodos EasyMesh, detalles de Wi-Fi 7 / MLO y diagnósticos de cobertura.
  • Descubrimiento Local: La app realiza consultas multicast en tu red local (mDNS en puerto UDP 5353, SSDP en puerto UDP 1900 y peticiones HTTP de descripción) exclusivamente en tu subred doméstica para identificar nombres amigables de fabricantes y modelos (impresoras, Smart TVs, domótica).
  • Almacenamiento: Las etiquetas personalizadas por el usuario (ej. «TV Salón») se almacenan únicamente en la memoria local de la app en tu teléfono. Ningún dato se sube a internet.

C. Telemetría de Fibra Óptica y Hardware

  • Datos tratados: Atenuación óptica GPON/XGS-PON (potencia Rx/Tx en dBm), voltaje del transceptor, corriente de polarización del láser y temperatura leídos directamente de los OIDs del router.
  • Finalidad: Ofrecer diagnósticos del estado físico de la fibra óptica y ayudarte a detectar conectores sucios, curvaturas excesivas o caídas inminentes de señal.
  • Almacenamiento: Se procesan en tiempo real en la memoria RAM del móvil; no se graban ni se envían a ningún servidor externo.

D. Generación de Código QR Wi-Fi

  • Datos tratados: Nombre de red (SSID) y contraseña de tu Wi-Fi.
  • Finalidad: Generar un código QR estándar para que tus invitados o dispositivos se conecten fácilmente a tu red.
  • Almacenamiento y Seguridad: Se genera íntegramente de forma local mediante dibujo vectorial en el móvil y la librería de código abierto ZXing. No se utiliza ningún servicio o API remota en la nube.

Herramienta Servicio Destino Datos Intercambiados Finalidad
